ЕГИПЕТ — ОФЛАЙН ЧЕК-ЛИСТ

1. Распакуйте архив.
2. Файл index.html можно открыть напрямую — чек-листы и сохранение отметок работают без сервера.
3. Для полноценной установки на главный экран как PWA (особенно iPhone) папку нужно один раз разместить на HTTPS-сайте (GitHub Pages / Cloudflare Pages / Netlify и т.п.). После первого открытия приложение будет работать офлайн.

Почему так: браузеры не разрешают Service Worker для обычных file:// файлов, поэтому PWA-установка требует HTTPS.

Данные хранятся локально в браузере устройства. Сервер и аккаунт не нужны.
